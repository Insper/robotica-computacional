# Capítulo 8 - SLAM
!!! pdf
    ![](slides.pdf)

Neste capítulo vamos utilizar o `Cartographer` para realizar SLAM (Localização e Mapeamento Simultâneos) e conhecer a navegação com o `Navigation2` (Nav2). Também vamos implementar uma ação `GoTo` para controlar o robô até uma coordenada.

## Atividades
As atividades deste capítulo focam em introduzir o conceito de SLAM na ROS 2 e controlar o robô precisamente para um ponto específico.

Esses conceitos serão explorados nas seguintes atividades:

- [Atividade 1](atividades/1-goto.md) - Implementação de um nó capaz de navegar até um ponto específico.
- [Atividade 2](atividades/2-slam.md) - SLAM com Turtlebot3
